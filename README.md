# stromplayz.github.io — redirector user site

This is **not** the FocusCaseX website. It only exists so that short
`stromplayz.github.io/...` links (and the legacy
`stromplayz.github.io/FocusCaseX-Marketplace/...` links) don't hit GitHub's
bare "There isn't a GitHub Pages site here" 404.

`index.html` / `404.html` map any path onto the official project site:

| Requested | Lands on |
| --- | --- |
| `/` | `/FocusCaseX/` |
| `/marketplace/` | `/FocusCaseX/marketplace/` |
| `/pricing/` | `/FocusCaseX/pricing/` |
| `/FocusCaseX-Marketplace/...` | `/FocusCaseX/...` |
| `/FocusCaseX/...` | unchanged (project site) |

Official site and repo:

- Site: https://stromplayz.github.io/FocusCaseX/
- Repo: https://github.com/stromplayz/FocusCaseX
